Bring agents into the editor.

MiawCode IDE is a desktop workspace built on Code - OSS with 30 bundled Subagent profiles and an internal MiawRouter provider.

There is no public repository, binary release, installer, or download link yet.

Development status

A working direction, not a public release.

MiawCode IDE is in active development. No public package or installer exists. The current gallery configuration also needs Open VSX before third-party distribution.
Code - OSS foundation

Editor services stay familiar

The workspace keeps language servers, debug adapters, terminals, keymaps, and extension surfaces from the Code - OSS base.

Gallery caveat

The development build currently points to Visual Studio Marketplace. A public fork must use a licensed alternative such as Open VSX.

MiawRouter provider

The bundled extension registers a miawrouter model provider and currently defaults to 127.0.0.1:21188.

Workspace definitions

Agent contracts, prompts, instructions, chat modes, and hooks load from project-level .miawcode directories.
